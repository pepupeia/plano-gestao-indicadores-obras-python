# Projeto de análise e controle de obras com Python, integrando planejamento, realizado, medição, custos e indicadores de desempenho.

> Projeto de estudo e desenvolvimento de um modelo de gestão e acompanhamento de obras, utilizando Inteligência Artificial, NotebookLM e Python para organização do conhecimento, análise de dados e construção de indicadores.

## 📌 Sobre o projeto

O gerenciamento de uma obra envolve diferentes dimensões de controle, como **planejamento, prazo, avanço físico, medição, custos e desempenho**.

Este projeto propõe a construção de um modelo conceitual para acompanhamento de obras, utilizando como base a comparação entre:

* **Planejado**
* **Realizado**
* **Medido**
* **Custo Orçado**
* **Custo Realizado**

A proposta faz parte de um desafio de aprendizagem ativa com Inteligência Artificial e utiliza o **NotebookLM como ferramenta de pesquisa, organização e análise do conhecimento**, complementando o estudo com **Python para tratamento de dados, cálculo de indicadores e visualização das informações**.

---

## 🎯 Objetivo
Desenvolver um modelo de gestão e indicadores para obras que permita analisar o desempenho físico, financeiro e temporal de uma obra a partir da comparação entre planejamento, execução e medição.

### Objetivos específicos

* Estudar conceitos fundamentais de planejamento e controle de obras;
* Compreender a relação entre planejado, realizado e medido;
* Estudar métodos de acompanhamento de custos;
* Identificar indicadores relevantes para gestão de obras;
* Estudar ferramentas como Curva S e Curva ABC;
* Compreender conceitos relacionados ao Earned Value Management;
* Utilizar o NotebookLM para organizar e consultar fontes técnicas;
* Desenvolver e testar prompts para aprendizagem e analise crítica;
* Utilizar Python para tratamento e analise de dados;
* Criar uma base conceitual para futuras aplicações de gestão de obras.

---

## 💡 Problema

Durante a execução de uma obra, o planejamento precisa ser constantemente comparado com aquilo que está sendo efetivamente executado e medido.

Uma das questões centrais deste projeto é:

> **Como estruturar um modelo de gestão que permita comparar o planejamento com o realizado e o medido, identificar desvios de prazo e custo e gerar indicadores capazes de apoiar a tomada de decisão?**

A partir dessa questão, o projeto busca organizar conhecimentos de gestão de obras e transformá-los em uma estrutura de análise baseada em dados.

# Aplicação com Python

Após a etapa de pesquisa e consolidação do conhecimento, será criada uma base de dados de exemplo representando informações de uma obra.

A estrutura poderá conter:

| Campo           | Descrição                 |
| --------------- | ------------------------- |
| Atividade       | Serviço ou etapa da obra  |
| Data            | Período de acompanhamento |
| Planejado       | Percentual planejado      |
| Realizado       | Percentual executado      |
| Medido          | Percentual medido         |
| Custo Orçado    | Valor previsto            |
| Custo Realizado | Valor executado           |

A partir desses dados serão desenvolvidos indicadores e análises utilizando Python.

Entre as análises previstas:

* Planejado × Realizado;
* Realizado × Medido;
* Orçado × Realizado;
* Desvio físico;
* Desvio financeiro;
* Curva S;
* Curva ABC;
* Indicadores de desempenho.

Os dados utilizados serão disponibilizados posteriormente em:

```text
data/
```
